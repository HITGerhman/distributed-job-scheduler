Operator Notes

怎么把这块舞台看明白

先看 MySQL，再看 RPC

这个项目的“真相”在 MySQL。动画只是把写库、派发和回调重新编排成肉眼可见的节奏。

心跳是关键拐点

一旦出现 heartbeat，就说明这不是停在 dispatched 的假热闹，而是 worker 真在执行。

Outbox 和 Audit 是后半程

业务状态先落库，再 relay，再 audit。看到这两个节点亮起，就代表主线闭环完成。

学习站默认连接 configs/local.yaml。如果依赖没起来，页面会直接告诉你卡在哪个环节。
